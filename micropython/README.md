# MicroPython projects

```
micropython/
└── tutorials/
    ├── 01-blink-led/            Blink the onboard LED
    └── 02-temperature-sensor/   Read the chip's temperature sensor
```

Each tutorial folder has its own `README.md` and a `main.py`. Work through them
in order. Add new tutorials as `NN-name/` folders in `tutorials/`.

To run or upload a tutorial, open its `main.py` and use the VS Code tasks
**Run current file on Pico (no save)** or **Upload current file to Pico as
main.py**. Setup instructions are in the [main README](../README.md).
