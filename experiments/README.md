# Experiments

Ten MicroPython experiments modelled on the topics of the Kitronik Inventor's
Kit for Pico. The code and READMEs here are original and written without access
to Kitronik's guides, so **pin numbers are assumptions**. Before running each
one, check the pin constants at the top of `main.py` against your kit's guide.

| # | Experiment |
|---|------------|
| 1 | [Digital inputs and outputs](01-digital-inputs-outputs/README.md) |
| 2 | [Light sensor and analog inputs](02-light-sensor-analog-inputs/README.md) |
| 3 | [Dimming an LED with a potentiometer](03-dimming-led-potentiometer/README.md) |
| 4 | [Using a transistor to drive a motor](04-transistor-motor/README.md) |
| 5 | [Controlling a servo with a potentiometer](05-servo-potentiometer/README.md) |
| 6 | [Setting the tone with a piezo buzzer](06-piezo-buzzer-tones/README.md) |
| 7 | [Using a seven segment display](07-seven-segment-display/README.md) |
| 8 | [Exploring wind power](08-exploring-wind-power/README.md) |
| 9 | [Capacitor charge circuit](09-capacitor-charge-circuit/README.md) |
| 10 | [Controlling ZIP LEDs](10-controlling-zip-leds/README.md) |

Open an experiment's `main.py` and use the VS Code tasks **Run current file on
Pico (no save)** or **Upload current file to Pico as main.py**. Setup is in the
[main README](../README.md).
