# Experiment 6: Setting the tone with a piezo buzzer

Play a musical scale on a piezo buzzer.

## What you'll learn

- Making sound by driving a pin at an audio frequency
- Using a dictionary of note frequencies

## Run it

Open [main.py](main.py) and use **Tasks: Run Task → Run current file on Pico
(no save)**.

## Check before running

`BUZZER_PIN` is an assumption; verify it against your kit's guide.

## Try it yourself

- Play a short tune by listing note names and durations.
- Change the pitch with a potentiometer (Experiment 3).
